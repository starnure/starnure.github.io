FAQ

Where should I buy?

Wherever you prefer. BuiltByBit, Voxel Shop and starnure.dev get the same jar and the same updates. Buying on starnure.dev directly means the full price goes to development.

Do I need a license key?

Yes. Start the server once, paste the key into plugins/<plugin>/license.yml and restart. Bought on BuiltByBit or Voxel Shop? Run /verify in our Discord to get your key. One key works on 3 servers; ask in support if you need more.

What happens if your license server is down?

Nothing you would notice. After the first activation the plugin keeps working offline for 7 days and checks again in the background.

Which server software is supported?

Each plugin lists its versions above. ToxicRain runs on Spigot, Paper and Purpur 1.18 - 26.3. Relics SMP targets Paper, Purpur 1.21.4 - 26.3 and Folia.

Can I get a refund?

If the plugin does not work on your server and we cannot fix it, write to support and we will refund you.

Can you add a feature?

Post it in the suggestions forum on Discord. Popular requests go into the next update.
